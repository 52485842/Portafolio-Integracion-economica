# Resumen de Clase

## Objetivo del Trabajo Práctico Modular

Este trabajo práctico tiene por objetivo integrar los contenidos desarrollados en las clases anteriores a través de un análisis comparado de los principales modelos de acumulación en la historia económica argentina. Se busca que el estudiante pueda identificar los elementos constitutivos de cada modelo, sus transformaciones y las condiciones que determinaron sus crisis.

## Marco teórico: ¿qué es un modelo de acumulación?

El concepto de **modelo de acumulación** (o régimen de acumulación, en la terminología regulacionista) refiere al conjunto articulado de:

1. Una **forma de organización de la producción** (técnica, relaciones laborales, tamaño de las empresas)
2. Un **modo de distribución** del ingreso entre salarios y ganancias
3. Una **forma de inserción internacional** (exportaciones, importaciones, flujos de capital)
4. Un **rol del Estado** en la economía
5. Una **estructura financiera** que articula el ahorro con la inversión

Un modelo es "coherente" cuando estos elementos se articulan de forma relativamente estable y permiten la reproducción ampliada del capital. Una "crisis de modelo" ocurre cuando las contradicciones entre sus elementos se vuelven irresolubles.

## Cuadro comparativo: modelos en Argentina

### Modelo agroexportador (1880-1930)

| Dimensión | Característica |
|-----------|---------------|
| Base productiva | Agropecuaria pampeana |
| Inserción internacional | Exportadora de cereales y carnes |
| Rol del Estado | Liberal, facilitador |
| Distribución | Concentrada en élite terrateniente |
| Financiamiento | Capital extranjero (inglés) |
| Crisis | Crack del '30 y caída de precios |

### ISI Peronista (1946-1955)

| Dimensión | Característica |
|-----------|---------------|
| Base productiva | Industria liviana |
| Inserción internacional | Orientación al mercado interno |
| Rol del Estado | Empresario y redistributivo |
| Distribución | Expansión salario real |
| Financiamiento | IAPI, banca pública |
| Crisis | Restricción externa, caída de reservas |

### Desarrollismo (1958-1962 y períodos posteriores)

| Dimensión | Característica |
|-----------|---------------|
| Base productiva | Industria pesada (acero, petróleo) |
| Inserción internacional | IED en sectores estratégicos |
| Rol del Estado | Planificador |
| Distribución | Subordinada a la acumulación |
| Financiamiento | IED, endeudamiento |
| Crisis | Inestabilidad política |

### Valorización financiera (1976-2001)

| Dimensión | Característica |
|-----------|---------------|
| Base productiva | Desindustrialización relativa |
| Inserción internacional | Apertura financiera |
| Rol del Estado | Subsidiario |
| Distribución | Regresiva |
| Financiamiento | Endeudamiento externo |
| Crisis | Default 2001 |

### Neodesarrollismo (2003-2015)

| Dimensión | Característica |
|-----------|---------------|
| Base productiva | Primario-exportadora + industria |
| Inserción internacional | Exportaciones con retenciones |
| Rol del Estado | Activo, redistribuidor |
| Distribución | Mejora del salario real |
| Financiamiento | Renta sojera, reservas |
| Crisis | Restricción externa, inflación |

## Eje de análisis: continuidades y rupturas

El análisis comparado permite identificar continuidades estructurales que atraviesan distintos modelos:

- La **restricción externa** como límite recurrente al crecimiento
- La **puja distributiva** como factor de inestabilidad política y económica
- La **dependencia de commodities** como fuente de volatilidad
- El **rol de la deuda externa** como mecanismo de ajuste y dependencia

# Aporte Externo

## La teoría de la regulación y su aplicación a Argentina

La escuela francesa de la regulación (Michel Aglietta, Robert Boyer, Alain Lipietz) ofrece herramientas conceptuales para analizar los modelos de acumulación. Su aplicación al caso argentino fue realizada por investigadores como Jorge Schvarzer y Eduardo Basualdo, quienes identificaron las formas institucionales específicas que articularon cada régimen de acumulación en Argentina.

Esta perspectiva permite superar tanto el determinismo económico (que ve las crisis como producto inevitable de contradicciones económicas) como el voluntarismo político (que las atribuye a errores de gobernantes) para entender las condiciones estructurales que habilitan o limitan los márgenes de acción de los actores.

# Opinión Personal

El ejercicio de análisis comparado de modelos resulta de gran utilidad analítica porque permite ver las continuidades que atraviesan los distintos períodos y gobiernos. En particular, me parece valioso reconocer que ciertos problemas argentinos —la restricción externa, la inflación, la vulnerabilidad ante shocks externos— no son atribuibles a un gobierno en particular sino que expresan tensiones estructurales más profundas.

Al mismo tiempo, el marco de modelos de acumulación no debe llevarnos a un determinismo que niegue la agencia política: distintas respuestas a las mismas restricciones estructurales tuvieron efectos distributivos muy diferentes.
